# Васькина Яна ИТС-2 Лабораторная №7

# Задание 1 - 10

### Текст задачи

В задании 1 в текстовом файле хранятся целые числа по одному в строке, исходный файл
необходимо заполнить случайными данными, заполнение организовать отдельным методом.
В задании 2 в текстовом файле хранятся целые числа по несколько в строке, исходный файл
необходимо заполнить случайными данными, заполнение организовать отдельным методом.
В задании 3 в текстовом файле хранится текст.
В задании 4 бинарные файлы, содержат числовые данные, исходный файл необходимо заполнить
случайными данными, заполнение организовать отдельным методом.
В задании 5 бинарные файлы содержат величины типа struct, заполнение исходного файла
необходимо организовать отдельным методом, обязательно использовать xml сериализацию,
решение без сериализации не принимается.
В задании 10 исходные данные хранятся в текстовом файле

### Алгоритм решения

Задание 1. Сумма элементов, оканчивающихся на заданную цифру
Тип данных: текстовый файл (task1.txt), числа по одному в строке
1. Создать файл и записать в него 20 случайных чисел (от 1 до 999), по одному в строке — метод GenerateTask1File
2. Спросить у пользователя цифру 0–9 с проверкой ввода — ReadDigitFromKeyboard
3. Открыть файл на чтение через StreamReader
4. Пока не конец файла — читать строку, превращать в число через int.TryParse
5. Для каждого числа вычислить последнюю цифру: Math.Abs(number % 10)
6. Если последняя цифра равна заданной — прибавить число к сумме
7. Вывести сумму

Задание 2. Разность первого и минимального элементов
Тип данных: текстовый файл (task2.txt), числа по несколько в строке
1. Создать файл: 5 строк по 4 случайных числа через пробел — GenerateTask2File
2. Открыть файл на чтение
3. Каждую строку разбить на числа (Split по пробелу и табуляции)
4. Первое встреченное число сохранить в first
5. Среди всех чисел найти минимум
6. Вывести разность

Задание 3. Строки без знаков препинания
Тип данных: текстовый файл (task3.txt) с текстом
1. Создать исходный файл с 4 строками стихотворения — GenerateTask3File.
2. Открыть исходный файл на чтение.
3. Для каждой строки проверить: есть ли в ней хотя бы один знак препинания из массива
4. Если знаков препинания нет — записать строку в список результатов
5. Записать список в новый файл task3_result.txt через File.WriteAllLines

Задание 4. Исключить повторные вхождения чисел
Тип данных: бинарный файл (task4.bin)
1. Создать бинарный файл с 20 случайными числами (от 1 до 14) — GenerateTask4File
2. Открыть файл через BinaryReader
3. Читать по одному int (ReadInt32), пока позиция меньше длины файла
4. Для каждого числа:
если его ещё не было — записать в List<int> order для сохранения порядка
5. Открыть новый файл через BinaryWriter
6. Записать в него все числа из order по порядку

Задание 5. Самая дорогая игрушка для детей 2–3 лет
Тип данных: XML-файл (task5.xml), структура Toy
1. Создать массив Toy[] с игрушками (название, цена, возрастные границы) — GenerateTask5File
2. Сериализовать массив в XML
3. Десериализовать файл обратно в массив Toy[]
4. Пройти по всем игрушкам, найти те, у которых:
AgeFrom <= 2 (подходит для 2 лет),
AgeTo >= 3 (подходит для 3 лет)
5. Среди подходящих выбрать игрушку с максимальной ценой
6. Вывести название и цену

Задание 6. Симметрическая разность списков L1 и L2
Тип данных: два списка чисел, ввод с клавиатуры
1. Считать L1 и L2 с клавиатуры
2. Из L1 и L2 построить HashSet<int> — для быстрой проверки Contains
3. Пройти по L1: если элемента нет в L2 и его ещё нет в результате — добавить в результат
4. Пройти по L2: если элемента нет в L1 и его ещё нет в результате — добавить в результат
5. Вывести результат.

Задание 7. Удалить элементы между min и max
Тип данных: LinkedList<int>, ввод с клавиатуры
1. Считать список чисел с клавиатуры в LinkedList<int>
2. Найти индексы минимального и максимального элементов
3. Определить начало и конец диапазона: start = min(minIdx, maxIdx), end = max(minIdx, maxIdx)
4. Если end − start < 2 — между ними ничего нет, выйти
5. Вторым проходом удалить все узлы, чей индекс строго между start и end 
6. Вывести получившийся список

Задание 8. Телевизионное шоу
Тип данных: список шоу + предпочтения N зрителей, ввод с клавиатуры
1. Считать общий список шоу
2. Спросить количество зрителей N
3. Для каждого зрителя считать множество шоу, которые ему нравятся
4. Для каждого шоу из общего списка посчитать, скольким зрителям оно нравится
5. Вывести три множества.

Задание 9. Какие цифры встречаются в тексте
Тип данных: текстовый файл (task9.txt)
1. Создать файл с 4 строками тестового текста — GenerateTask9File
2. Прочитать весь текст через StreamReader.ReadToEnd()
3. Пройти по каждому символу: если c >= '0' && c <= '9' — добавить в HashSet<char>
4. Вывести множество цифр (дубликаты автоматически отсеиваются)

Задание 10. Самый старший человек (по дате рождения)
Тип данных: текстовый файл (task10.txt) с записями <Фамилия> <Имя> <ДД.ММ.ГГГГ>
1. Создать файл с 5 человеками — GenerateTask10File
2. Открыть файл на чтение
3. Каждую строку разбить на 3 част
4. распарсить дату через DateTime.TryParseExact с форматом dd.MM.yyyy;
сохранить в Dictionary<string, DateTime> (ключ — ФИО, значение — дата)
Пройти по Dictionary:
если дата меньше текущей «самой старшей» — обновить, countOldest = 1;
если равна — увеличить countOldest.
Если countOldest == 1 — вывести ФИО самого старшего.
Иначе — вывести количество людей с одинаковой самой старшей датой.
